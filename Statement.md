# Workout Progress Tracker

## Problem Statement

People who work out regularly need to keep a record of their exercises, weight, sets and repetitions. If these details are written down manually, it can become difficult to remember previous workouts and compare the progress.

This project is made to provide a simple way to enter workout details, save them and check them later.

## Scope of the Project

The project is a simple desktop application for recording workout details.

The user can enter the exercise name, weight, sets and repetitions. The information is saved in a JSON file and can be viewed later through the application.

The project mainly focuses on basic workout recording, workout history and progress tracking.

## Target Users

This application can be used by:

* People who go to the gym
* People who exercise regularly
* Beginners who want to keep a record of their workouts

## High-Level Features

* Add workout details
* Save workout details in a JSON file
* View previous workout records
* View workout progress
* Check incorrect input using basic validation
